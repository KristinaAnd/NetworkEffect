🎯 Что показывает этот график: Зависимость между количеством связей между агентами и общей эффективностью системы.

📈 Интерпретация точек: Каждая цветная точка — отдельная модель. Точки в верхней правой части графика показывают модели с высокой плотностью и высоким сетевым эффектом.

👥 Влияние числа агентов на сетевой эффект

🎯 Что показывает этот график: Закон Меткалфа гласит, что ценность сети пропорциональна квадрату числа участников (n²). Здесь видно, как увеличение числа агентов влияет на сетевой эффект.

📈 Интерпретация точек: Каждая точка — отдельная модель. Если точки образуют восходящий тренд, это подтверждает закон Меткалфа — каждый новый участник увеличивает ценность для всех остальных.

• Уравнение регрессии:

🧮 Сетевой эффект = {{ agents_slope|floatformat:6 }} × (Количество агентов) + {{ agents_intercept|floatformat:4 }}

• Вывод: {% if agents_correlation > 0.5 %} 📈 Подтверждается действие закона Меткалфа. Рекомендуется стратегия масштабирования сети. {% else %} 📉 Эффект масштаба не проявляется в полной мере. Возможные причины: недостаточная плотность связей или неоптимальная топология. {% endif %}

• 📌 Практическая рекомендация: Добавление новых агентов потенциально увеличит ценность сети.

⚖️ Влияние весов связей на сетевой эффект

🎯 Что показывает этот график: Вес связи отражает интенсивность взаимодействия между агентами (например, объем поставок, частоту коммуникаций). Чем выше вес, тем сильнее связь. Для невзвешенных графов все веса = 1.

📈 Интерпретация точек: Каждая точка — взвешенная модель. Если точки образуют восходящий тренд, укрепление существующих связей так же эффективно, как и создание новых.

• Уравнение регрессии:

🧮 Сетевой эффект = {{ weight_slope|floatformat:6 }} × (Средний вес) + {{ weight_intercept|floatformat:4 }}
