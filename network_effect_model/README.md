# 🌐 NetEffect Modeler

**Веб-приложение для моделирования сетевого эффекта в организационно-замкнутых экономических системах**

## 📖 Описание

NetEffect Modeler — инструмент на базе Django для генерации, анализа и визуализации сетевых взаимодействий между агентами (до **1000**). Рассчитывает структурный, функциональный и общий сетевой эффект, эффективность цепочки поставок, бизнес-ценность, уровень риска, синергию по закону Меткалфа. Включает интерактивный дашборд с регрессионным анализом (корреляция Пирсона, линейная регрессия) и экспорт результатов в JSON, CSV, Excel, HTML/PDF.

## ✨ Основные возможности

- **Генерация графов** – количество агентов (2–1000), число связей, направленность (directed/undirected), взвешенность (weighted/unweighted), сбалансированность (для directed – автоматическое добавление обратных рёбер).
- **Расчёт ключевых метрик**:
  - Плотность сети (D) – по формуле из документа.
  - Сбалансированность (B) – индекс Херфиндаля по степеням узлов.
  - **Структурный эффект** = N × D × B.
  - **Функциональный эффект** = сумма весов рёбер (для невзвешенных – количество рёбер).
  - **Общий сетевой эффект (TNE)** = √(структурный × функциональный).
  - **Эффективность цепочки поставок** – агрегация пропускной способности, устойчивости, избыточности (0..1).
- **Бизнес-метрики**:
  - Ценность сети по закону Меткалфа = n².
  - Бизнес-ценность = TNE × n².
  - Уровень риска = (1 – √(D × B)) × 100%.
  - Мультипликатор синергии = TNE × n.
  - Экономический эффект от добавления одного агента = (( (n+1)² / n²) – 1) × эффективность_цепочки × 100%.
- **Аналитический дашборд**:
  - Три графика (плотность → TNE, число агентов → TNE, средний вес → TNE) с линиями тренда.
  - Коэффициент корреляции Пирсона и уравнение линейной регрессии (автоматическая обработка случаев с отсутствием вариации данных – корреляция = 0, NaN исключены).
  - Статистическая сводка: средние, медиана, перцентили, стандартное отклонение, потенциал роста.
- **Автоматические рекомендации** – формируются на основе порогов плотности, риска, сбалансированности и эффективности.
- **Экспорт** – JSON, CSV, Excel (многостраничный), HTML/PDF (с визуализацией графа через Matplotlib).

## 🚀 Установка и запуск

### 1. Клонирование и подготовка
```bash
Клонирование репозитория
git clone <[repository-url](https://github.com/KristinaAnd/NetworkEffect.git)>

Перейдите в директорию проекта
cd network_effect_model

Создайте виртуальное окружение
python -m venv venv

Активируйте виртуальное окружение
1. Windows:
venv\Scripts\activate
2. Linux/macOS:
source venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Инициализация базы данных
```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. Запуск сервера
```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу: http://127.0.0.1:8000

## 📤 Экспорт данных

В приложении реализовано несколько форматов выгрузки результатов:

- 📄 **JSON** — полная структура модели, метаданные, граф, все метрики и рекомендации
- 📊 **CSV** — Плоская таблица с основными метриками (модель, агенты, плотность, эффекты, риск)
- 📈 **Excel (.xlsx)** — многостраничный отчет с метаданными, метриками и таблицами
- 📑 **PDF/HTML** — Полноценный отчёт с визуализацией графа, интерпретацией и рекомендациями (Ctrl+P → "Сохранить как PDF")

## 💡 **Особенности реализации**

- Все графики на дашборде строятся через Chart.js (интерактивность) и matplotlib (статические для PDF)
- Регрессионный анализ и коэффициенты корреляции рассчитываются через scipy.stats и numpy
- Бизнес-рекомендации формируются динамически на основе пороговых значений метрик
- Приложение оптимизировано для работы в локальной сети или на сервере компании
- Весь код модульный, легко расширяем для добавления новых метрик или типов графов

## 📐 **Методология расчета**

| Показатель                 | Формула / Источник                                                                                 |
|----------------------------|----------------------------------------------------------------------------------------------------|
| Плотность (D)              | Для undirected: \( 2E / (N(N-1)) \); для directed: \( E / (N(N-1)) \)                              |
| Сбалансированность (B)     | \( B = \frac{(\sum \deg)^2}{N \sum \deg^2} \) (индекс Херфиндаля)                                 |
| Структурный эффект         | \( N \cdot D \cdot B \) (поле `structural_effect`)                                                 |
| Функциональный эффект      | Сумма весов рёбер (для unweighted – \( \text{num\_edges} \))                                       |
| Общий сетевой эффект       | \( \sqrt{\text{structural} \times \text{functional}} \)                                            |
| Эффективность цепочки      | Взвешенная сумма `throughput`, `resilience`, `redundancy` (результат в [0,1])                      |
| Бизнес-ценность            | \( \text{total\_effect} \times \text{num\_agents}^2 \)                                             |
| Уровень риска              | \( \left(1 - \sqrt{D \cdot B}\right) \times 100\% \)                                               |
| Мультипликатор синергии    | \( \text{total\_effect} \times \text{num\_agents} \)                                               |
| Экономический эффект       | \( \left( \frac{(n+1)^2}{n^2} - 1 \right) \times \text{efficiency} \times 100\% \)                 |
| Корреляция Пирсона         | \( \text{np.corrcoef}(x, y)[0,1] \) (если `len(set(x)) > 1`, иначе 0)                              |
| Линейная регрессия         | \( \text{stats.linregress}(x, y) \) (только при наличии вариации \(x\))                           |
